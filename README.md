# SunnyForHumor 幽默訓練器

把一段相聲／脫口秀逐字稿裡的笑點拆開來學，用語音跟 App 對練，最後寫出自己的梗。

## 怎麼開啟

純前端網頁（無需安裝套件），可直接部署到 GitHub Pages，用手機打開後「加入主畫面」就像 App 一樣使用。

本機測試：

```bash
python3 -m http.server 8000
```

然後打開 http://localhost:8000 。（語音辨識需要 `https` 或 `localhost` 才能使用麥克風。）

## 功能

| 分頁 | 做什麼 | 語音 |
|---|---|---|
| 📚 學習 | 5 個段子逐一拆解：鋪陳 → 先猜 → 揭曉 → 意思A／意思B 對照 → 公式 | 🔊 單人示範（笑點前自動停頓）、🎭 雙人原版重現、🎤 用說的猜答案 |
| 🗺️ 場景 | 依生活情境（颱風天、一天的時間、養老院、友情…）整理段子、素材與收集；可新增自訂場景；「實戰模擬」練習聽到情境就接梗 | 🔊 朗讀情境、🎤 接梗評分 |
| 🎯 猜梗 | 4 選 1：從「合理答案」中找出真正的笑點 | 🔊 朗讀題目與答案 |
| 🎤 表演 | 搭檔對練：你講鋪陳 → App 當搭檔問「為什麼？」→ 你講笑點，自動評分並量接話節奏；錄音自評 | 語音辨識 + 語音合成 + 錄音 |
| ✍️ 創作 | 雙關詞庫 + 兩種公式引導，寫自己的段子並即時檢查 | 🎤 口述成文字、🔊 朗讀成品 |
| 📒 收集 | 笑點收集本：原句、為什麼好笑、技巧類型、來源，可篩選、匯出 | 🎤 語音快速記錄 |
| ⚙️ 設定 | 主角／搭檔聲音、語速、笑點前停頓長度 | |

設計說明見 [docs/DESIGN.md](docs/DESIGN.md)。新增段子只要編輯 `js/data.js`。
