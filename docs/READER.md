# 🔊 朗讀器

移植自 [wordstovoice](https://github.com/sunnywin99/wordstovoice) 的讀書筆記網頁（`notes_web/template.html`），整理成所有單元都能用的元件 `js/reader.js`。

## 功能

| 功能 | 說明 |
|---|---|
| ▶ ❚❚ ■ | 每段都有播放／繼續、暫停、停止；暫停後從那一句重新念 |
| 單一／連續播放 | 連續播放念完這段會自動接下一段 |
| 每句連續三遍 | 重複前先說「第二遍」「第三遍」，適合跟讀 |
| 標出正在念的句子 | 外框亮起、畫面自動捲動跟著走；念過的字畫紅線，還沒念的畫主色線（裝置有回報念到第幾個字時） |
| 長句自動切小段 | 超過 120 字的句子在逗號處切開（不切括號內），避免瀏覽器念到一半停住 |
| 略過不念的內容 | 文獻出處（Smith, 2019）、（p. 19），以及跟讀記號｜【】：畫面照樣顯示，朗讀時跳過 |
| 設定共用 | 語速（0.5～2 倍）、聲音、播放方式、每句次數存在設定裡，所有頁面通用 |

## 用在哪裡

- **🔊 朗讀室**：貼上文字或開啟 .txt（自動辨識 UTF-8／Big5／GB18030），切段規則同 wordstovoice 的 `build.py`（空行分段、短行當標題）；記住上次念到哪一段。內建三份文稿：幽默段子原稿（標示主角／搭檔）、說話五公式、跟讀稿。
- **🗣️ 說話訓練 → 跟讀**：每句是一個朗讀段落，旁邊有 🎤 跟讀評分。

## 程式用法

```js
container.append(Reader.playerBar());          // 語速、聲音、播放方式、每句次數
container.append(Reader.block('第一句。第二句。', {
  label: '主角',                                 // 顯示在按鈕旁，不會念出來
  html: Reader.markHtml                           // 可選：把【】顯示成粗體
}));
Reader.stop();
```

## 和 wordstovoice 的差別

- wordstovoice 的桌面程式用 edge-tts（微軟線上神經語音）轉成 MP3，需要 Python。網頁版改用瀏覽器內建語音；用 **Microsoft Edge** 開啟時，聲音清單會有同一組台灣神經語音（HsiaoChen、YunJhe…），App 會自動排在最前面。
- 雲端同步（筆記、閱讀位置跨裝置）沒有移植，資料存在這台裝置的瀏覽器。
