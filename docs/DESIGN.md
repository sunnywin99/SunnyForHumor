# 幽默訓練器設計說明

## 1. 從逐字稿看到的規律

稿子中的 5 個笑點，全都用同一個機制：**一個詞有兩種意思，鋪陳讓你想到 A，笑點換成 B。**

| 段子 | 關鍵詞 | 意思 A（觀眾以為） | 意思 B（笑點） | 公式 |
|---|---|---|---|---|
| 這輩子太短了 → 蓋不到腳 | 輩子／被子 | 人生 | 棉被 | 1 同詞雙解 |
| 不能往後 → 往後的日子不好過 | 往後 | 向後方 | 未來 | 1 同詞雙解 |
| 颱風天帶四千萬 → 沒事千萬不要出門 | 千萬 | 金額 | 務必 | 2 怪規定＋成語理由 |
| 壞事中午做 → 早晚會有報應 | 早晚 | 遲早 | 早上和晚上 | 2 怪規定＋成語理由 |
| 不紅住養老院 → 有翻身的機會 | 翻身 | 逆轉命運 | 身體翻面 | 2 怪規定＋成語理由 |

所以 App 不只是「背段子」，而是教**可重複使用的公式**：鋪陳 → 停頓 → 反轉 → 加碼。

## 2. 學習路徑（由理解到產出）

1. **理解**（學習頁）：先讓使用者自己猜，再揭曉。「猜錯」本身就是學習——體驗到被反轉的感覺。
2. **辨識**（猜梗）：錯誤選項都是「合理但不好笑」的答案，訓練大腦去找「換意思」的那個。
3. **表演**（搭檔對練）：幽默是說出來的。App 扮演捧哏，練接話節奏與停頓。
4. **創作**（工坊）：套用兩種公式，用雙關詞庫寫自己的梗。
5. **收集**（收集本）：日常輸入，持續擴充素材，形成「收集 → 拆解 → 改寫」循環。

## 3. 語音功能設計

全部使用瀏覽器內建 Web Speech API，免費、免伺服器、免 API 金鑰：

- **語音合成（TTS）**：`speechSynthesis`，優先挑 zh-TW 語音。
  - 單人示範：鋪陳 →（可調停頓）→ 笑點放慢 10% → 加碼。讓使用者「聽到」節奏。
  - 雙人原版：主角與搭檔用不同聲音（沒有第二個聲音時調高音調區分）。
- **語音辨識（STT）**：`SpeechRecognition`（zh-TW）。
  - 評分 = 字句相似度（最長共同子序列）60% + 關鍵詞命中 40%。關鍵詞沒講到 = 雙關不成立。
  - 接話節奏：搭檔問完到使用者開口的時間，0.4～1.8 秒為理想。
  - 數字正規化：辨識出的「4,000萬」會轉成「四千萬」再比對。
- **錄音回放**：`MediaRecorder`，自己聽自己的語氣。

支援度：Chrome／Edge（電腦、Android）全功能；iOS Safari 14.5+ 支援辨識；Firefox 只有朗讀。不支援時會顯示提示並保留其他功能。

### 之後可升級

- 換成雲端 TTS（如 Azure／Google 的台灣中文神經語音）讓聲音更自然，或直接用原表演者音檔片段。
- 用音訊分析偵測「笑點前的實際停頓長度」與音量起伏。
- 接上 AI，針對使用者寫的段子給改寫建議、自動產生新的雙關詞。

## 4. 技術架構

- 純 HTML/CSS/JS，無建置步驟，hash 路由；PWA（manifest + service worker）可加入主畫面、離線使用。
- 資料全部存在 `localStorage`（進度、作品、收集本、設定）。
- 檔案：`js/data.js` 段子與詞庫／`js/theory.js` 幽默原理／`js/speech.js` 語音與評分／`js/app.js` 頁面。
